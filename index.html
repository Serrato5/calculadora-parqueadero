Cómo funciona

La lógica nació como un programa de consola en Python y luego la pasé a esta versión web. Las reglas son las mismas: valida los datos, calcula el valor por horas, aplica el tope diario y clasifica la permanencia.

  • ValidaciónRechaza tipos de vehículo inválidos, horas fuera de 1 a 24 y texto no numérico.
  • Tope diarioSi el valor por horas supera el máximo, solo se cobra el máximo.
  • Clasificación1–2 h corta, 3–5 h media y 6–24 h prolongada.
Ver el código en Python 
tarifas = {1: ("Motocicleta", 2000, 12000),
           2: ("Automóvil", 4000, 24000)}

try:
    tipo = int(input("Tipo de vehículo (1 moto, 2 carro): "))
    horas = int(input("Horas de permanencia: "))
except ValueError:
    print("Error: ingrese números enteros.")
else:
    if tipo not in tarifas:
        print("Error: tipo de vehículo inválido.")
    elif not 1 <= horas <= 24:
        print("Error: las horas deben estar entre 1 y 24.")
    else:
        vehiculo, tarifa, maximo = tarifas[tipo]
        clasificacion = ("Corta" if horas <= 2
                         else "Media" if horas <= 5
                         else "Prolongada")
        valor = horas * tarifa
        total = min(valor, maximo)
        print("Vehículo:", vehiculo)
        print("Permanencia:", clasificacion)
        print(f"Valor por horas: ${valor:,}")
        print("Tope aplicado:", "Sí" if valor > maximo else "No")
        print(f"Total a pagar: ${total:,}")
